# SALIERI’S HANDS — Press Kit Notes

Artist: KAMDRIDI  
Label: KAMDRIDI RECORDS  
Release type: Special off-series album  
Status: Official teaser out now. Album coming soon.  
Tagline: Vienna, 1791. Faith. Envy. Confession.

## Summary
SALIERI’S HANDS is a KAMDRIDI classical / dark baroque concept release. It uses the Salieri myth as a dramatic symbolic frame for original KAMDRIDI compositions. It is not a historical biography.

## Credits
All music written, produced, arranged and performed by KAMDRIDI.  
Released by KAMDRIDI RECORDS.
