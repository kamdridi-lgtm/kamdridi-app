## ⚡ Quick Start (5 minutes)

### 1) Ouvrir le site localement

```bash
# Option A: Python
cd dreamgirl-ai
python -m http.server 8000

# Option B: Node.js
npx serve

# Ouvre dans ton navigateur:
# http://localhost:8000
```

### 2) Explorer les pages

- `index.html` — Landing page de vente
- `gallery.html` — Galerie de sélection
- `studio.html` — Génération vidéos
- `admin.html` — Dashboard admin

### 3) Tester le flow

1. Cliquer sur un plan (ex: **Plus — $5**)
2. Sélectionner 1–2 photos
3. Cliquer **Continue to Studio**
4. Générer une vidéo (simulation)
